# Glyph-on privacy / プライバシー

Glyph-on stores your Glyphs, appearance, shortcuts, window preferences, and up to three automatic settings backups on your device. You can see the storage path in **Settings → Data**. Exports stay wherever you save them and can include paths, command text, and optional custom icons. Environment variable values are never stored by the command editor. Keep credentials out of Glyph names, descriptions, paths, command text, and arguments.

The app has no account, analytics, telemetry, or automatic diagnostic uploads. Checking for updates connects to GitHub. Selecting a report link opens GitHub in your browser. The browser, a launched application, or a command can make its own network requests. Share only the information you choose to include when filing a report.

Glyph-onは、Glyph、外観、ショートカット、表示設定、直近3世代までの自動バックアップを端末内に保存します。保存先は **設定 → データ** で確認できます。エクスポートファイルは指定した保存先に作成され、パスやコマンド本文、選択に応じてアイコンを含みます。コマンド編集画面では環境変数の値を保存しません。名前、説明、パス、コマンド本文、引数には認証情報を入力しないでください。

アカウント登録、利用状況の収集、テレメトリー、診断の自動送信はありません。更新を確認するとGitHubに接続し、報告リンクを選ぶとブラウザーでGitHubを開きます。起動先のアプリやコマンド、ブラウザーは独自に通信する場合があります。報告時は共有する内容を確認できます。
