# Reporting a security issue / セキュリティ問題の報告

Use the repository's private vulnerability reporting form when available. Include the Glyph-on version, OS version, observed behavior, and a safe way to reproduce it. Avoid attaching settings, command contents, or credentials unless needed and explicitly redacted. [Private security report](https://github.com/skphotograph/glyph-on/security/advisories/new)

GitHubの非公開の脆弱性報告フォームが利用できる場合は、そちらを使用してください。Glyph-onとOSのバージョン、発生した挙動、安全な再現条件を記載してください。設定ファイルやコマンド本文を添える必要がある場合は、先に認証情報などを伏せてください。[非公開のセキュリティ報告](https://github.com/skphotograph/glyph-on/security/advisories/new)

The maintainers review the report privately, coordinate a fix and disclosure date with the reporter, and document the fix in a security advisory or release note after affected users can update.

管理者は報告を非公開で確認し、報告者と修正・公開日を調整します。影響を受ける利用者が更新できる状態になってから、アドバイザリまたはリリースノートで修正内容を案内します。
